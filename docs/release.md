# Подготовка выпуска

1. Обновить версию согласованно в `pyproject.toml` и CLI управления.
2. Выполнить `make check` и проверки установленной версии из `testing.md`.
3. Проверить полный состав изменений и актуальность README.
4. Проверить исходники и всю историю Git с Gitleaks с включённой редактировкой
   секретов в выводе. Дополнительно проверить локальные пути и приватные данные.
5. Выполнить `make release`. Архив содержит только разрешённые исходные файлы;
   рабочий каталог, конфигурация установленной службы и логи в него не входят.
6. Проверить архив и `SHA256SUMS`, затем публиковать согласованный тег и выпуск.

Архив исходников не содержит двоичных зависимостей Homebrew. `build-info.json`
остаётся локальным манифестом фактически проверенной сборки. На другой системе
получившаяся сборка должна проходить те же проверки.

Нельзя включать в публикацию `work/`, `outputs/`, личные инструкции, логи,
пароли старых тестовых запусков, данные устройств и метаданные установленной
службы. `.gitignore` не заменяет проверку индекса, истории и архива.
