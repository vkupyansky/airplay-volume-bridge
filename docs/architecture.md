# Устройство службы

Сетевой приёмник основан на закреплённом Shairport Sync 5.6.3. Он использует
Bonjour macOS, принимает обычный AirPlay и выводит аудио через CoreAudio.
Собственный протокол, драйвер звука и приложение на iPhone не требуются.

## Громкость

Команда AirPlay содержит значение от −30 до 0; −144 означает mute.
Интеграция переводит значение в системный диапазон 0…1 и использует публичные
свойства CoreAudio. Собственное ослабление потока отключено, поэтому громкость
не применяется дважды. Mute сохраняет прежний уровень громкости.

Начальное значение и последующие команды телефона применяются под одним mutex.
Начальное значение выбирается после захвата блокировки. Это предотвращает
перезапись свежей команды устаревшим начальным значением.

Данные проверяются до обращения к звуковому устройству. После записи выполняется
короткое подтверждение чтением. Ошибка применения не выдаётся за успешную
RTSP-команду. Лимит ожидания чтения не является гарантией времени выполнения
системного API.

## Жизненный цикл

`local.airplay-volume-bridge` — пользовательский LaunchAgent в GUI-сеансе.
launchd управляет одним процессом `receiver`, без root и собственного daemonize.
`KeepAlive` обеспечивает постоянную готовность, `ThrottleInterval` ограничивает
частоту аварийного перезапуска. Остановка через CLI сохраняет disabled-состояние.

Python используется только при вызове команд установки и управления. Во время
воспроизведения он не работает. На частые команды громкости не создаются
процессы, фоновые очереди и таймеры опроса.

## Файлы и диагностика

| Данные | Место |
| --- | --- |
| Двоичные файлы и CLI | `~/Library/Application Support/airplay-volume-bridge/bin/` |
| Конфигурация | `~/Library/Application Support/airplay-volume-bridge/config/receiver.conf` |
| Регистрация launchd | `~/Library/LaunchAgents/local.airplay-volume-bridge.plist` |
| Журнал | Unified Logging, subsystem `local.airplay-volume-bridge` |

Каталоги службы имеют права 0700, конфигурация и plist 0600. Установщик проверяет
новую сборку до остановки действующей, атомарно заменяет файлы и сохраняет
конфигурацию. Удаление службы не удаляет конфигурацию.

Исходный шаблон конфигурации — `config/receiver.conf`. Настройки громкости и
аутентификации в нём не дублируются в переменных окружения. Пароль отсутствует
по выбранному сценарию домашней сети. Привязки к Apple Account нет.

Системный журнал ограничивается средствами macOS. Шаблон сообщения доступен
публично, значения аргументов скрыты privacy-разметкой. Обычные изменения
громкости по умолчанию не журналируются.

## Проверенная сборка

Первый локальный выпуск собран с Shairport Sync 5.6.3, FFmpeg 8.1.2,
OpenSSL 3.6.4, libconfig 1.8.3, popt 1.19 и Apple Clang 21.0.0.
Управляющие команды проверены на Python 3.15.2. Инструменты проверок:
Ruff 0.17.4 и mypy 2.4.1, закреплённые в `uv.lock`.

Исходный архив приёмника и патчи закреплены; библиотеки предоставляет Homebrew.
Это воспроизводимая процедура сборки из проверяемых исходников, а не обещание
побайтово одинакового бинарника при любых версиях системных библиотек.
