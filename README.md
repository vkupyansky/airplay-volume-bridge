# AirPlay Volume Bridge

Локальная служба macOS: принимает музыку с iPhone по AirPlay и позволяет
регулировать системную громкость Mac обычным ползунком и кнопками телефона.

**[Скачать исходники v0.1.0](https://github.com/vkupyansky/airplay-volume-bridge/releases/download/v0.1.0/airplay-volume-bridge-0.1.0-source.tar.gz)** · [Выпуск и SHA256SUMS](https://github.com/vkupyansky/airplay-volume-bridge/releases/tag/v0.1.0)

## Возможности

- Apple Music на iPhone передаёт звук на динамики Mac.
- Громкость телефона меняет системный регулятор Mac, включая mute.
- Один нативный процесс на C, без отдельного процесса на каждое нажатие.
- Запуск при входе в систему и восстановление после сбоя через launchd.
- Работа без приложения на iPhone, облака, аккаунта и пароля подключения.
- Проверка готовности, команды управления и системный журнал macOS.

## Установка и запуск

Проверенная платформа: macOS 27.2.1, Apple Silicon. Для сборки нужны
Xcode Command Line Tools, Homebrew и Python 3.15. На других версиях macOS
и Intel Mac работоспособность пока не подтверждена.

Распакуй архив выпуска, открой терминал в его каталоге и выполни:

```sh
brew install autoconf automake pkgconf libconfig popt openssl@3 ffmpeg python@3.15
make install
```

Сборка загружает Shairport Sync 5.6.3, проверяет SHA-256 и применяет локальные
патчи. Уже установленные зависимости Homebrew сохраняются. Двоичные файлы
собираются на твоём Mac; готовые исполняемые файлы в архив не включены.

Установка размещает службу отдельно от исходников, запускает её и включает
автозапуск. Права администратора не нужны. При повторной установке сохраняются
конфигурация и явное отключение пользователем.

## Использование

1. Подключи iPhone и Mac к одной Wi-Fi-сети.
2. Включи трек в Apple Music на iPhone.
3. В списке AirPlay выбери **Mac Volume Bridge**.
4. Меняй громкость кнопками или ползунком iPhone. Изменится системная громкость Mac.

Пароль не требуется. Подключаться смогут устройства в той же сети;
используй службу в доверенной домашней сети и не открывай её порт в интернет.

Управление установленной службой работает и после удаления каталога исходников:

```sh
BRIDGE="$HOME/Library/Application Support/airplay-volume-bridge/bin/airplay-volume-bridge"
"$BRIDGE" status
```

| Команда | Действие |
| --- | --- |
| `start` | Запустить и разрешить автозапуск |
| `stop` | Остановить и отключить автозапуск |
| `restart` | Корректно перезапустить |
| `status` | Показать регистрацию, процесс и готовность RTSP |
| `check` | Проверить файлы, конфигурацию, зависимости и аудиовыход |
| `logs` | Показать события службы за последний час |
| `version` | Показать версию |
| `uninstall` | Удалить службу, сохранив конфигурацию и данные |

Для обновления распакуй новый выпуск и снова выполни `make install`.
После ранее выполненного `stop` потребуется явный `start`.

## Проверки

Для разработки дополнительно нужен [uv](https://docs.astral.sh/uv/).
Версии инструментов закреплены в `uv.lock`.

```sh
make check
```

Команда собирает C-код с предупреждениями как ошибками, запускает тесты,
строгую проверку типов, Ruff и статический анализ. Протокольный тест использует
отдельный локальный порт и не меняет громкость. Проверки установленной службы
и сценарии с iPhone описаны в [тестировании](docs/testing.md).

## Ограничения

- Используется обычный AirPlay, один аудиопоток. AirPlay 2 и multiroom не включены.
- Это отдельный приёмник; в списке AirPlay нужно выбрать именно его.
- Управление направлено от iPhone к Mac. Клавиши Mac не обязаны сдвигать ползунок iPhone.
- Нужен звуковой выход с программной регулировкой громкости. HDMI и некоторые USB-ЦАП
  могут её не предоставлять; служба сообщает об ошибке вместо фиктивного успеха.
- Homebrew-библиотеки нужны и после установки; их нельзя удалять, пока служба используется.
- Не выполнена нотарификация Apple. Исходники собираются и подписываются локально.
- Подключение после сна и пробуждения Mac пока не проверено.
